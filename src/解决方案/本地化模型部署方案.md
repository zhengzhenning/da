# 服务器检查

## 检查并安装NVIDIA驱动

### 检查NIVIDIA驱动

> 检查服务器是否安装 NIVIDIA驱动

```shell
#查询GPU信息
nvidia-smi
```

```shell
#查询驱动模块加载情况
lsmod | grep nvidia
```

```shell
#查询系统中NIVIDIA相关包
rpm -qa | grep nvidia
```

### 安装NIVIDIA驱动

> 查看NVIDIAGPU型号

```shell
[root@192 modprobe.d]# lspci | grep -i nvidia
01:00.0 VGA compatible controller: NVIDIA Corporation AD102 [GeForce RTX 4090] (rev a1)
01:00.1 Audio device: NVIDIA Corporation AD102 High Definition Audio Controller (rev a1)
```

> 确认系统是否启用Nouveau开源驱动

```shell
[root@192 modprobe.d]# lsmod | grep -i nouveau
[root@192 modprobe.d]# 
```

> 若启用，则需禁用系统自带的Nouveau开源驱动；若无，也提前配置禁用

```shell
###检查是否有相关配置文件
[root@192 modprobe.d]# pwd
/etc/modprobe.d
```

# 知识库部署

部署需求：

1. 支持开放API集成
2. 支持私有知识库管理（按应用隔离）

目前，市场主流知识库框架有六种：

- **AnythingLLM（⭐️45.9k+）**
- **MaxKB（⭐️16.9k+）**
- **RAGFlow（⭐️58.5k）**
- **FastGPT（⭐️24.9k）**
- [**Dify（⭐️105k+）**](https://github.com/langgenius/dify) 
-  **Open WebUI（⭐️101k+）** 

选型参考文档：

1. [选型建议1：AnythingLLM、Dify 与 Open-WebUI有何不同](https://zhuanlan.zhihu.com/p/15981735869)。
2. [选型建议2：Open WebUI和Dify](https://zhuanlan.zhihu.com/p/1895601805632708908)。
3. [选型建议3：AnythingLLM、Dify、Open-WebUI对比](https://mcp.csdn.net/68356795606a8318e85a8a0f.html)。

综合分析后，Dify 有更完善的[开放API](https://docs.dify.ai/zh-hans/guides/application-publishing/developing-with-apis)以及更贴合生产实际的知识库管理功能，因此选择**Dify**作为知识库工具。

相关文档：

1. **[Dify-API](https://docs.dify.ai/zh-hans/openapi-api-access-readme)**。涵盖对话消息、文件操作、语音文字转换等
1. [快速安装Dify指南](https://zhuanlan.zhihu.com/p/1896300442687895533)。
1. [Dify-Docker Compose 部署](https://docs.dify.ai/zh-hans/getting-started/install-self-hosted/docker-compose)。
